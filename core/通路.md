# 设备通路与工具使用

## 操作规则

1. 从仓库根目录运行，先读目标 `core/apps/<App>.md`。每次操作前查看当前页面，用户可能自行切页。
2. 控件树优先，截图兜底；执行一个动作后验证结果，再执行下一步。失败时重新定位，不沿用后续坐标。
3. 发布、发送、删除按本次授权执行；支付、密码和生物识别由用户本人完成。遇到验证页或异常页面暂停。
4. 操作间留出页面响应时间，可加入随机停顿；停顿不能保证避免平台验证。
5. 输入完恢复安卓原输入法。收工只停止本次任务启动且仍归本任务使用的进程。

## iPhone

首次安装、WDA 签名及环境变量见 [iPhone 配置](iphone-setup.md)。手机 USB 连接、解锁亮屏，连接成功后使用：

```bash
bash core/tools/ios_wda.sh
python3 core/tools/ios.py tree
python3 core/tools/ios.py shot /tmp/iphone-screen.png
```

### 命令与定位

| 子命令（接在 `python3 core/tools/ios.py` 后） | 作用 |
|---|---|
| `tree [关键词]` | 读取可见控件文字、类型、中心坐标 |
| `tapt 文字 [序号]` | 按文字定位点击，优先全等，再包含 |
| `shot [文件]` | 保存截图并缩放到点坐标 |
| `tap X Y` | 按点坐标点击 |
| `swipe X1 Y1 X2 Y2 [秒]` | 滑动，秒数为起点停留时间，默认 0.05 |
| `type 文字` | 向当前焦点输入框输入，支持中文 |
| `clipboard 文件 包名` | 准备长文本剪贴板并切回目标 App，随后在界面粘贴 |
| `url 网址` | 用手机默认浏览器打开网址 |
| `home` / `launch 包名` / `apps [关键词]` | 回桌面、打开 App、查询 App |

具体参数以 `--help` 为准。坐标是 iOS 的「点」，以当前截图输出为准；不同机型、显示缩放和方向不能共用固定值。

### 操作经验

- `tree` 适合数字、选中状态和开关状态；图片网格、进度外观用截图。
- 整行开关的中心可能落在文字上，先用截图核对右侧开关本体。
- 共享面板里目标头像会延迟出现；按文字选目标，避免坐标碰到联系人。
- `swipe` 停留过久会变成长按；先用默认值。键盘弹出时先收起，避免滑动落在键盘上。
- 长文本先存文件，用剪贴板输入后回读全文；控件树的截断预览不能证明全文一致。
- 同一动作每次都核对：权限弹窗、空列表、上传中和审核中都可能改变下一步。

## 安卓

### 准备与选择设备

准备 Python 3 和 adb（Android Platform Tools）；中文输入另需 [ADB Keyboard](https://github.com/senzhk/ADBKeyBoard) 安装到手机。开启开发者选项与 USB 调试，在手机确认信任电脑。

```bash
adb devices
export ANDROID_SERIAL='<目标设备序列号>'
adb shell wm size
adb shell settings get secure default_input_method
```

`ANDROID_SERIAL` 对所有 adb 工具生效；多台设备必须选定。小米的模拟点击可能还要求「USB调试（安全设置）」。账号登录和验证由本人完成。

### 控件树与点击

```bash
python3 core/tools/ui.py
python3 core/tools/ui.py 设置
python3 core/tools/tap.py 设置 --dry
python3 core/tools/tap.py 设置
bash core/tools/hput.sh focus
```

全屏原生页面的控件树通常能直接提供点击位置；H5、自绘、分屏需核对截图。页面无控件时，不能推断整个 App 都无控件。

### 截图与坐标

```bash
bash core/tools/hput.sh shot screen
```

默认图片写入临时目录 `phone-agent/`，可设置 `PHONE_AGENT_SHOT_DIR`。原图坐标可直接使用；缩小后分别按 `原宽/显示宽`、`原高/显示高` 还原 x、y。旋转或分屏后重新测量，不套用旧设备的倍率。

```bash
bash core/tools/hput.sh tap 100 200
bash core/tools/hput.sh swipe 200 600 200 200
```

`hput.sh` 带延迟和轻微抖动，小目标优先用文字定位。动作后再次读控件或截图。

### 中文输入与恢复输入法

```bash
bash core/tools/hput.sh text '要输入的中文'
```

先点击目标输入框；工具临时借用 ADB Keyboard，使用 base64 广播输入并恢复原输入法。可用 `ANDROID_IME` 明确指定恢复目标；原来已是 ADB Keyboard 时需先指定日常输入法。输入法列表：`adb shell ime list -s`。
输入后回读正文，检查换行、话题符号和长度。清空编辑框的方法依 App 而异，未验证清空不要继续追加文字。

### 视觉模型（可选）

控件树读不到时可使用阿里云百炼识别截图。这两个工具会上传当前屏幕并产生 API 调用费用。先确认截图和调用属于用户授权范围。

设置 `DASHSCOPE_API_KEY`，或用 `DASHSCOPE_ENV_FILE` 指向包含 `DASHSCOPE_API_KEY=...` 的文件。无需依赖作者本机目录。

```bash
python3 core/tools/see.py '搜索框'
python3 core/tools/see.py --ask '页面有哪些按钮？'
bash core/tools/see.sh '搜索框'
```

先核对返回坐标，再决定点击。`see.py --tap` 和 `see.sh -t` 会识别后直接点击，只在目标清楚且允许执行时使用。两工具使用不同模型和坐标解释，换模型时应重新核对坐标。

## 经验记录与验证范围

- App 路径与坑写进 `core/apps/`；工具变更同步参数和本文件，任务资料单独放 `tasks/`。
- 已跑通的固定流程可进一步参数化；脚本每步写验证条件，失败停止，修复后更新脚本。
- 本次分享版完成语法、配置和模拟响应验证。原操作路径来自真实设备实践；不同朋友的设备仍需首次连接和逐步实测。
