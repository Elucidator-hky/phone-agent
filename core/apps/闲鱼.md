## 已跑通的路径

### 发布房源
`首页金刚区「租房」→ 右下角「+ 发布房源」`

1. 进租房频道弹定位权限 → 选「仅在使用中允许」
2. **城市默认当前定位（会是你人在的城市），必须改成房子所在城市**；进「房屋地址」后**城市又变回去，要再改一次**
3. 依次填：分类（住房出租）/ 出租方式（整租）/ 地址（搜小区名）/ 房源类型（转租）/ 户型 / 面积 / 更多信息 / 价格

5. 图片：点击顺序 = 展示顺序
6. **标题和正文是同一个文本域，第一行自动当标题** → 必须一次性输入「标题\n正文」。分两次点会插进标题中间，把标题截断
7. 右上角「发布」

## 坑

**⚠️ 2026-08-06 闲鱼不支持 emoji**
描述里带 📍🏠💰 会被拒绝发布：「亲，您的标题或描述里面有表情，现在我们还不支持哦」，输入框顶部也会提示"暂不支持表情输入，否则会被过滤"。
闲鱼版文案必须用【】标签排版，发布前跑一遍：
```python
re.sub(r'[\U0001F000-\U0001FAFF☀-➿️]', '', text)
```

**⚠️ 2026-08-06 输入框的 Ctrl+End 不跳文档末尾**
只能删光标前面的内容，后面的必须用 `FORWARD_DEL`（keycode **112**）往后删。小红书那边 Ctrl+End 是正常的。
清空闲鱼文本域要前删后删都来一遍：
```bash
adb shell input keycombination 113 123
BACK=$(python3 -c "print(' '.join(['67']*150))")
FWD=$(python3 -c "print(' '.join(['112']*150))")
for i in $(seq 1 8); do adb shell "input keyevent $BACK"; done
for i in $(seq 1 8); do adb shell "input keyevent $FWD"; done
```

**2026-08-06 价格填完点确定可能不保存**
发布时会弹"你还没有填写价格" → 点「去填价格」重填一次，回表单确认显示 `¥1800.00/月` 再发。

**2026-08-06 编辑页图片区的 `+` 直接跳相机**
弹相机权限，不是相册。加图/加视频只能重新发布整条。
