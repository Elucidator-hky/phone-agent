# 闲鱼

## 基本情况

安卓 `com.taobao.idlefish`；iPhone `com.taobao.fleamarket`。
安卓原生首页、导航曾可用控件树定位，H5 频道页可能读不到文字；先看当前 Activity 和控件树，再决定截图。全屏和分屏分别验证坐标，不把某次窗口缩放当成 App 固有比例。

## 已跑通的路径

### 安卓发布 / 编辑房源

首页租房入口 →「发布房源」→ 分类、出租方式、地址、户型、面积、价格 → 图片 → 文案 → 核对 → 按发布授权提交。
- 当前定位城市可能与房源城市不同；填写地址后再次核对城市。
- 户型滚轮使用滑动，点文字可能不选中。
- 图片勾选顺序决定展示顺序。
- 实测房源编辑器把正文第一行当标题：一次输入「标题 + 换行 + 正文」，回读确认。
- 改价后返回表单核对显示值，再发布。
编辑入口：我的 → 我发布的 → 目标内容「编辑」。发布后回读详情，不凭点击成功判断发布成功。

### iPhone 编辑正文和图片

商品页「管理按钮」→「编辑」，或我的 → 我发布的 → 编辑。
正文先保留原文和目标全文，聚焦正文 → 长按 → 全选 → 粘贴。长文本用 `python3 core/tools/ios.py clipboard <文本文件> com.taobao.fleamarket` 准备剪贴板，随后立即粘贴；核对全文后完成并按授权发布，再回详情核对。
图片「+」可能先打开拍摄页，再点「相册」。只有部分照片权限时通过「添加更多可选照片」授权本次图片，返回勾选 → 下一步 → 完成。保留未要求修改的图片。
2026-10 的上传会压缩长图：多页参数建议拆成多张，发布后检查文字清晰度，而不是只检查图片数量。

### 搜索商品与核对价格

搜索 → 筛选 → 商品详情 → 核对型号、配置、成色、实拍和运费。价格区间设置后回读是否生效；标题与参数栏不符时标为待核。
详情显示验货服务时，记录实际条款；运费和服务费以确认页可见合计为依据，查看时不提交订单。卖家自动回复中的事实仍需核对。

## 坑

- 控件树为空不等于页面空白，截图确认 H5 / 自绘内容。
- 2026-08 某些发布页不接受 emoji；以编辑器提示为准。
- 安卓闲鱼编辑框曾不支持 Ctrl+End 跳末尾，清空后必须检查光标前后是否仍有旧文。
- 图片「+」的行为因平台和版本变化；iPhone 可从拍摄页进入相册，勿沿用安卓旧路径。
- 剪贴板可能被其他复制动作覆盖；准备和粘贴紧接执行，最终以发布页全文为准。

## 红线

发送、发布、改价按授权执行；不自动付款。验证码、登录和身份验证交给用户。出现平台限制时停止，不以重复操作规避。
