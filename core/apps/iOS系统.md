# iOS 系统（设置 / 语音备忘录 / 照片）

## 基本情况

2026-10 在 iPhone 16 上验证，使用 WDA 和 `core/tools/ios.py`，设置、录音列表的控件树可读。
设置 `com.apple.Preferences`；语音备忘录 `com.apple.VoiceMemos`；照片 `com.apple.mobileslideshow`。
先按 [iPhone 配置](../iphone-setup.md) 建立连接。以下 `tree`、`tapt`、`type` 等均指 `python3 core/tools/ios.py` 的子命令。

## 已跑通的路径

### 查看存储、删除 App

设置首页搜索 → 输入「iPhone储存空间」→ 点结果 → 等待统计完成。用 `tree` 读取已使用 / 总量及 App 排序；点 App 后查看「App大小」「文稿与数据」。
用户指定删除该 App 后：点「删除App」→ 核对连同数据删除的提示 → 确认 → 回列表再次检查包名和存储。区别「卸载App」（保留文稿与数据）与「删除App」。

### 设置粘贴权限

设置 → App → 指定 App →「从其他App粘贴」→「允许」→ 返回上一页读回状态。2026-10-19 实测只有曾询问过粘贴权限的 App 显示这一项；没有全局开关。按本次需求修改对应 App。

### iCloud 同步与数据清理

设置 → Apple 账户 → iCloud →「已存储到 iCloud」的「查看全部」。
- 列表开关用 `tree` 读取状态；控件中心可能在文字上，必要时截图定位右侧开关本体。
- iCloud照片、云盘、密码与钥匙串、备忘录等需进入各自子页面。
- 每次读取完整提示：有「在iPhone上保留」时按备份方案选择；只有「从iPhone删除」或提示未上传改动时，先确认影响再继续。
- 清理云端数据：iCloud →「储存空间」→ 目标 App → 读取删除 / 停用提示；按明确授权确认，返回核对容量。
- 同一账户的其他设备会受同步删除影响；关闭同步与删除云端数据是两件事。

### 语音备忘录备份到 Mac

1. 「所有录音」用控件树记录名称、日期、时长；同名录音按名称和日期区分。
2. 「选择」→ 分批选中目标行 → 用「已选定N项」和 `checkmark.circle.fill` 核对。
3. 「共享」→ 按文字找「隔空投送」→ 按目标 Mac 名称选择；等「已发送」。大批录音先按 5–8 条一批处理，再根据实际耗时调整。
4. Mac 上核对接收文件的数量、大小及完整时长。同名文件可能被重命名，名称不能作为唯一依据；近似时长也要结合文件内容或其他信息确认。
5. 复制到不会被 iCloud 同步删除的位置，确认每条备份可读后再按授权删除原件。

「正在下载…」表示录音尚未完整落在手机；先等待下载完成。「最近删除」另行保留，只有明确授权永久删除时才清空。

### 照片删除与传输

删除：照片 → 图库 → 选择 → 选目标照片 → 核对选中数量 → 删除。图片网格用截图识别，固定坐标和一次拖选数量会随屏幕改变；分批操作，每批回读。打开「最近删除」需要面容 ID 或密码时由用户本人完成。

Mac 传照片：把本次图片复制到单独临时目录 → 在该目录运行 `python3 -m http.server 8765 --bind <Mac局域网IP>` → 同一局域网的手机用 `ios.py url http://<IP>:8765/01.jpg` 打开 → 长按图片，按当前浏览器菜单保存到相册 → 核对数量。完成后停止本次启动的服务。首次权限弹窗按传图需求处理。

### App Store 下载

App Store → 搜索 → 输入 App 名 → 核对名称和开发者，排除广告结果 → 点「获取」或「重新下载」→ 观察下载进度。账户认证、付费确认由用户本人处理。

## 坑

- 列表翻页的 `swipe` 秒数是起点按住时长；先用默认 0.05，长按可能打开菜单。
- 共享面板第一排会出现联系人，目标 Mac 可能晚出现；按文字选目标，找不到就等待。
- Mac 锁屏时可能不出现在隔空投送列表；请用户解锁，观察「等待中 / 正在准备 / 已发送」。
- 录音准备和转换可能较慢；每 10–20 秒检查状态，一分钟没有变化先查原因。
- iCloud 同步目录可能包含 0 字节占位文件；核对大小和可播放性，独立备份后再删。
- 键盘弹出时坐标滑动可能输入字符；先确认键盘收起，再滑页面。
- 使用者若在操作 Mac，后台执行手机命令，避免打开会切换焦点的桌面窗口。
