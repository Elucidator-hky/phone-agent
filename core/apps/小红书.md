# 小红书

## 基本情况

- 包名：`com.xingin.xhs`
- **全屏原生 App，控件树完全可读，dump 坐标 = 真实坐标，直接可用** —— 优先用 `core/tools/tap.py 文字` 按文字点击，不要截图
- 平板上：图文相册页竖屏，其余页面横屏。坐标系数不变
- 账号：小夏今天也要快乐（35 粉丝，素人号，权重低）
- 正文限 **1000 字**，标题限 **20 字**

> 2026-08-06 之前一直以为 dump 坐标不可信（那是闲鱼分屏的结论），全程截图硬看，浪费大半天。
> 实测：`首页(320,2030) 市集(960,2030) 消息(2240,2030)` 与截图算出的完全一致。

## 已跑通的路径

### 发图文笔记
`底部「+」→ 从相册选择 → 点图片右上圆圈选中 → 下一步(N) → 下一步 → 填标题/正文 → 发笔记`
- 点击顺序 = 展示顺序，第一张是封面
- 标题和正文是**两个独立输入框**（跟闲鱼不同）
- 验证点：每步后 `adb shell dumpsys window | grep mCurrentFocus` 确认 Activity 变了

### 发视频笔记
同上，相册里选带时长标记的视频 → 视频编辑页直接「下一步」→ 填标题/作品描述 → 发笔记
- **图文笔记里不能混视频**，视频必须单独发一条
- 两条笔记正文里互相指路（"另外发了条视频笔记，点我主页看"）能互相导流

### 编辑已发布笔记
`我 → 点笔记 → 底部「编辑和权限设置」→ 面板里点「编辑」`
- 视频笔记详情页是 feed 流，点「编辑和权限设置」坐标偏一点就滑到下一条笔记了，要点在文字上
- 编辑后会重新过审，会掉推荐流量。**改动尽量一次到位**

### 加话题
- **横屏下点 `#` 按钮不弹联想列表**（竖屏会弹）
- 解法：把 `#广州租房 #黄埔租房 ...` 当**纯文本**用 base64 输进正文，**发布后小红书会自动识别成蓝色话题** —— 实测有效
- 素人号别用大话题（`#广州租房` 10.7 亿浏览会沉底），用 `#暹岗` `#萝岗租房` 这类小话题

### 标记地点（本地流量关键）
`点「标记地点」→ 搜索框输小区名 → 跨城市能搜到（右侧显示城市名）→ 选中打红勾 → 完成`

### 回私信
`消息 → 点对话 → 点输入框（平板横屏会进全屏编辑模式）→ 输入 → 点右侧「完成」→ 再点红色「发送」`

### 回评论
`消息 → 评论和@ → 点「回复」→ 输入 → 「发送」`

## 坑

**2026-08-06 清空正文极难**
- `ADB_CLEAR_TEXT` 广播不生效
- `input keycombination 113 29`（Ctrl+A）不生效，反而删掉一个字符
- 长按弹「全选」菜单**时灵时不灵**，失败时新文本会追加到旧文本后面（出现过 1828/1000 字超限）
- ✅ 可靠解法：
  ```bash
  adb shell input keycombination 113 123           # Ctrl+End 跳文档末尾（小红书有效）
  KEYS=$(python3 -c "print(' '.join(['67']*150))")
  for i in $(seq 1 8); do adb shell "input keyevent $KEYS"; done
  ```

**2026-08-06 发布按钮位置不固定**
图文笔记编辑页的发布按钮，有时在右上角，有时在底部（"发布笔记"红色长条）。发布前先确认。

## 红线

- **正文和评论绝不能出现手机号、微信号、"V"、"薇"** → 笔记限流（不进推荐池，等于白发）甚至封号。检测覆盖变体写法、数字拆分、图片 OCR
- 私信里发联系方式会弹「请使用官方经营工具完成交易」警告，**但消息正常送达**，一对一发风险可控；号码拆开发（150 7147 7738）能规避关键词
- ✅ 折中方案：正文放**个人网站域名**（如 hekaiyuan.top），域名不是标准联系方式特征，风险低。2026-08-06 实测有效，有租客通过网站加了微信
