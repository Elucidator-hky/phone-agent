# 小红书

## 基本情况

安卓包名 `com.xingin.xhs`；iPhone 包名 `com.xingin.discover`。2026-08 安卓全屏原生页面实测控件树可读，优先 `tap.py`；iPhone 使用 `ios.py`，每页重新确认控件可见性。平板可能自动横竖屏切换。

## 已跑通的路径

### 发布图文 / 视频

底部「+」→ 从相册选择 → 勾选目标图片 → 下一步 → 编辑 → 填标题与正文 → 核对预览 → 按发布授权提交。
图片勾选顺序决定展示顺序，第一张为封面；标题和正文是两个输入框，分别核对。视频从相册选带时长标记的条目进入视频编辑，按当前版本支持的素材类型处理。
发布后回个人主页找到作品，核对文字、图片顺序和发布状态；遇到待审核不重复发布。

### 编辑、话题与地点

我 → 目标笔记 →「编辑和权限设置」→「编辑」→ 修改 → 核对后提交。编辑可能重新审核，尽量一次改全。
2026-08 平板横屏的 `#` 按钮没有联想列表；纯文本话题发布后曾被识别，仍需回读实际效果。
「标记地点」→ 搜索目标地点 → 核对城市 → 选择 → 完成。

### 私信和评论

私信：消息 → 目标对话 → 输入框 → 输入草稿 → 核对联系人、文字。评论：消息 → 评论和@ → 回复 → 输入草稿。发送必须符合本次授权。

## 坑

- 发布按钮可能在顶栏或底部，不能沿用上一次坐标。
- 长按全选、ADB_CLEAR_TEXT 或 Ctrl+A 在某些编辑框无效；先验证内容是否清空再输入。安卓小红书曾支持 Ctrl+End 后退格，但需每批回读，避免超量删改。
- 编辑后回读正文，防止旧文未清空导致新旧内容拼接。
- 图文发布页可能竖屏，进入下一页后变横屏；截图与控件坐标需重新读取。

## 红线

平台出现交易引导或违规提示时停止相应操作，按平台允许的方式联系；发布及回复以用户明确授权为准。
