# 微信

## 基本情况

安卓 `com.tencent.mm`；iPhone `com.tencent.xin`。
控件树表现因设备和页面不同：2026-08 安卓平板可读，2026-10 红米的部分页面为空。先读控件树，必要时截图；支付、登录页可能限制截图。

## 已跑通的路径

起草消息：打开微信 → 用户指定的会话 → 核对联系人 → 点输入框 → 安卓用 `hput.sh text`，iPhone 用 `ios.py type` → 回读草稿。
默认由用户点击发送；当次明确授权直接发送时，发送前核对联系人和全文，发送后核对结果。不确定是否发出时先核实，避免重复。
存储清理见 [安卓系统](安卓系统.md)，聊天记录与缓存分别处理。

## 坑

- 空控件树需截图验证，不能从一次可读推断全版本可读。
- 登录或支付页截图全黑时由用户处理。
- 中文输入后恢复原安卓输入法，避免影响用户自己打字。

## 红线

只处理获授权的本人事务；不查看其他人的私人聊天。账户验证、密码和支付由本人完成。
