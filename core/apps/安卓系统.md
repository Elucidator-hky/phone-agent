# 安卓系统（存储体检 / 清理）

## 基本情况

2026-10 在 Redmi K50 等设备上实测。通过 adb 操作，多台设备时先 `export ANDROID_SERIAL=<目标序列号>`；以下命令继承该选择。
USB 调试入口随厂商变化，小米在版本号连点启用开发者选项；手机上确认信任电脑。模拟点击可能还需要「USB调试（安全设置）」。

## 已跑通的路径

### 只读体检

```bash
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.security_patch
adb shell cat /proc/meminfo
adb shell df -h /data
adb shell dumpsys diskstats
adb shell dumpsys battery
```

`diskstats` 的 `Package Names / App Sizes / App Data Sizes / Cache Sizes` 数组按索引对应；App 与数据相加排序，缓存单独列出。统计可能滞后，以系统存储界面复核。
共享目录大小可用 `adb shell du -sk /sdcard/DCIM /sdcard/Pictures /sdcard/Movies /sdcard/Download`，权限拒绝不代表目录为空。排序放到 Mac 端，部分安卓 `sort` 没有 `-h`。
电池当前电量、温度和状态不能直接等同于健康百分比；系统未提供的健康信息标成未知。

### 清缓存

用户同意清理缓存后可运行 `adb shell pm trim-caches 999G`，让系统尽可能回收可清缓存；系统可能限制执行，完成后 `df -h /data` 回读。
QQ：账户与设置 → 设置 → 通用 → 存储空间 → 缓存数据「清理」→ 确认 → 核对缓存量。
微信：我 → 设置 → 存储空间 → 等统计完成 → 缓存「清理」→ 核对勾选范围 → 确认 → 回读释放容量。
「聊天记录」「聊天文件」「原图原视频」与缓存分开，按主人指定范围处理。

## 坑

- `INJECT_EVENTS permission`：小米可能尚未打开「USB调试（安全设置）」。
- 微信在某些设备上控件树为空；此时截图定位并按当前尺寸换算。
- 对家人的设备，只读取存储设置及操作按钮，避免把聊天列表作为整页材料保存。
- 小米未安装的系统更新包可能在 `/sdcard/Download/downloaded_rom/`；先确认用途再决定处理。

## 红线

只在机主授权范围内操作；检查空间时不打开私人聊天和文件。删数据前核对备份，清理后记录前后容量。
