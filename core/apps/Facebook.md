# Facebook（安卓 App）

## 基本情况

包名 `com.facebook.katana`。主界面 `FbMainTabActivity`、设置 `ImmersiveActivity`、账户中心都能用控件树读到文字，坐标准确，用 `tap.py` / `ui.py`。
2026-10-20 在 vivo Y33s 上经授权只读查看账号状态时跑通下面的路径。

## 已跑通的路径

### 查账号状态（只读）

1. 打开设置：`adb shell am start -a android.intent.action.VIEW -d "fb://settings"` → 「设置与隐私」页
2. 点「账户中心」→「主页和个人详情」：本号名字、「你管理的公共主页」、联系信息、出生日期
3. 「联系信息」：绑了哪些邮箱和手机号
4. 返回账户中心 →「密码和安全」→「登录位置」→ 点账户名：本机和其它设备的登录地点、时间
5. 「密码和安全」→「双重验证」只列出账户名，再往里点要输密码，只读查看到这一步为止
6. 手机上存了哪些号：设置页右上角头像（个人主页切换工具）→「账户切换接入点」，列出已保存的号；看完点「关闭」

每步用 `ui.py` 确认到了预期页面再走下一步。

## 坑

- 2026-10-20：个人主页左上角的汉堡「菜单」点了没反应，改用 `fb://settings` 进设置
- 2026-10-20：`https://accountscenter.facebook.com/...` 加 `-p com.facebook.katana` 打开不会跳进 App 的账户中心
- 2026-10-20：切到不是当前登录的已保存号会要求输密码（进 `FbExperimentalLoggedOutBloksActivity` 登录页）。不输，点左上「关闭」回到选号页，再点原来的号就能免密回去

## 红线

- 别人的号只读：不改设置、不发内容、不加删好友
- 切换账户或出现登录验证时停下，由账户持有人处理
- 密码由机主本人输入
- 操作放慢：每步间隔 8 秒以上
