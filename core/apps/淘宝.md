# 淘宝

## 基本情况

iPhone 包名 `com.taobao.taobao4iphone`；网页 `taobao.com` / `tmall.com`。
网页操作需要用户自己配置的浏览器自动化工具和登录状态，本仓库不包含浏览器连接器。

## 已跑通的路径

网页搜索 → 核对目标型号 → 进详情 → 选择颜色、内存、容量、套餐 → 等价格刷新 → 记录所选配置和价格。列表价通常为最低配置起价。
2026-10 页面曾使用 `[class*="valueItem--"]` 表示规格选项，带 `isDisabled` 的选项不可选；页面改版时按可见文字重新定位。
搜索页「百亿补贴」是筛选条件，开启后仍需逐条核对型号，避免把替代推荐记成目标商品。
iPhone 首页百亿补贴入口可进频道，但实测连续触发滑块与重新登录时应停止自动化，让用户查看。

## 坑

- 未登录时网页搜索可能一直显示加载中。
- SKU 已切换但价格没变时，等待或重新打开对应页面，确认刷新后才记录。
- 补贴价显示异常时以当前具体配置页为准，不能把一个商品的异常价格推广到全部网页商品。
- 淘宝和闲鱼登录状态可能各自失效，分别核对。

## 红线

登录验证、滑块和密码由用户处理；出现持续验证后停止重试。查价不提交订单或支付。
