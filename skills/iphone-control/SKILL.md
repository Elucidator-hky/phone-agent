# 操控 iPhone

## 通路与开工

`PHONE_AGENT_HOME` 指向本插件所在的 phone-agent 仓库根目录，Skill、工具和操作记录均在同一仓库。按 README 启动时已设置；若通过插件加载且未设置，使用本插件的 `${CLAUDE_PLUGIN_ROOT}` 作为根目录，并在每次 shell 命令中设置该路径。

1. 检查 `PHONE_AGENT_HOME` 已设置且目录存在；未配置时按仓库的 [安装说明](https://github.com/Elucidator-hky/phone-agent/blob/main/core/iphone-setup.md) 配置。目录下须有 `core/tools/ios.py` 和 `core/tools/ios_wda.sh`。
2. 阅读 `$PHONE_AGENT_HOME/core/iphone-setup.md`，按说明检查 Python 3、填写设备配置；工具自动读取仓库根目录的 `.env`。从 `cd "$PHONE_AGENT_HOME"` 启动；先确认用户的手机已解锁并通过 USB 连接 Mac。
3. 执行 `bash core/tools/ios_wda.sh`，输出 `READY` 后才操作。启动失败按安装说明检查解锁、信任、UI 自动化与签名状态。
4. 读 `core/apps/<目标App>.md`。已有路径按手册走；手册不存在时先读控件树，再探索并记录。

## 命令

运行 `python3 core/tools/ios.py --help` 查看当前工具支持的参数。常用命令如下：

| 命令 | 作用 |
|---|---|
| `shot [路径]` | 截图，缩放到点坐标，图上的 x、y 可用于 `tap` |
| `tree [关键词]` | 列出可见控件的类型、文字和中心坐标 |
| `tapt 文字 [序号]` | 按文字点按，全等优先、包含匹配其次；重名用序号 |
| `tap X Y` | 按点坐标点按 |
| `swipe X1 Y1 X2 Y2 [秒]` | 滑动；秒数是起点按住时长，默认 0.05 |
| `type 文字` | 输入文字，支持中文 |
| `clipboard 文件 包名` | 准备长正文剪贴板并切回目标 App，再在界面粘贴 |
| `url 网址` | 用手机默认浏览器打开网址 |
| `home` / `launch 包名` / `apps [关键词]` | 回桌面、启动 App、查询包名 |

屏幕大小以当前截图和工具输出为准，不能照搬其他设备的坐标。

## 操作与验证

1. 先 `tree` 读控件，只有图片、布局或树不可读时才 `shot`。
2. 能用 `tapt` 就按文字点；坐标点按前先看当前截图。
3. 每个动作后用 `tree` 或 `shot` 验证到了预期页面，再走下一步。批量操作逐批核对。
4. 输入前确认焦点和旧内容；粘贴长文后回读全文，发布后核对实际结果。
5. 每步之间随机停 2–6 秒；等待任务每 10–20 秒查看状态，持续一分钟无进度时检查原因并换方法。

## 已验证的技巧

- `Switch` 控件的值和选中标记优先从树读取；整行开关中心可能落在文字上，点开关本体前看截图定位。
- 共享面板的联系人头像会延迟出现。按「隔空投送」和用户指定的设备名称定位，找不到就等待，避免用固定坐标选接收人。
- `swipe` 按住过久会变成长按。优先使用当前 `--help` 支持的命令，并按 `core/通路.md` 定位、操作和验证；流程需要工具尚未支持的长按或拖选时，由用户完成该步后再继续。
- 列表条目按名字加日期匹配，序号会随页面加载变化。
- Mac 向手机传照片、语音备忘录隔空投送、相册与 App Store 操作见 `core/apps/iOS系统.md`。
- 拼多多查价见 `core/apps/拼多多.md`；出现实名认证由用户本人完成。淘宝 App 的验证可能反复触发，价格查询可转网页，具体见 `core/apps/淘宝.md`。

## 本人操作的边界

- 支付、密码、指纹、刷脸由用户本人完成；购买或发送等动作以用户本次授权为准。
- 微信默认只起草，用户按发送；只有用户本次明确要求直接发送才执行。
- 验证码、滑块、实名认证、重新登录或账号风险提示出现时暂停自动化，让用户处理后继续。
- 只访问用户授权的数据；用户使用 Mac 时，优先后台命令，避免切换其桌面。

## 记录与收工

新路径、踩坑和 App 限制写进 `core/apps/<App>.md`；设备连接知识写进 `core/iphone-setup.md`。重复流程固化到 `core/tools/`，记录命令、参数和每步成功条件。记录操作方法与验证条件，任务素材另放任务目录。

结束前确认 WDA 没有其他任务在用；需要关闭时执行 `bash core/tools/ios_wda.sh stop`。
